# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this repository, please report it
to ANS in line with our Vulnerability Disclosure Policy:

- Email: dpo@ans.co.uk
- Policy: https://www.ans.co.uk/wp-content/uploads/2024/01/POL-ANS-Vulnerability-Disclosure-Policy.pdf

Please do not disclose the issue publicly until it has been triaged and, where applicable,
a fix has been released.
